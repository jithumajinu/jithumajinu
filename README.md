## 🤖 AI & Community

I'm excited about where **agentic AI** is heading – systems that don't just answer, but plan, use tools and get real work done. I've been learning in the open and meeting the community, including an **[AAIF](https://aaif.io/)** (Agentic AI Foundation, part of the Linux Foundation) event in Tokyo.

**Open standards and projects I'm keeping an eye on:**

| Project | What it is |
|---|---|
| [**Model Context Protocol (MCP)**](https://modelcontextprotocol.io/) | A protocol for connecting LLM apps to external data sources and tools |
| [**Agent2Agent (A2A)**](https://a2a-protocol.org/) | An open protocol for AI agents to communicate and collaborate |
| [**AGENTS.md**](https://agents.md) | A simple, open format for guiding coding agents |
| [**goose**](https://block.github.io/goose/) | An open source, extensible AI agent |
